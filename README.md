# L'aventure des sons

Jeu pédagogique de lecture pour tablette et téléphone : sons complexes, syllabes, lettres proches, dragon et récompenses.

## Publier le jeu

1. Télécharger le fichier **index.html** fourni dans la conversation ChatGPT.
2. Dans ce dépôt, choisir **Add file → Upload files**, déposer `index.html`, puis valider avec **Commit changes**.
3. Ouvrir **Settings → Pages** ; dans **Build and deployment**, choisir **Deploy from a branch**, sélectionner **main** et **/(root)**, puis **Save**.
4. Après publication, ouvrir **https://anlito.github.io/aventure-des-sons/**.

## Notes

La progression est conservée localement dans le navigateur de l'appareil. Le jeu utilise actuellement la synthèse vocale du navigateur : les syllabes isolées ne sont pas encore des enregistrements audio pédagogiques. L'amélioration prévue consiste à ajouter une banque de sons enregistrés, puis un cache hors ligne.
